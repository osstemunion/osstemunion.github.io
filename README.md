# 금속노조 오스템임플란트지회 홈페이지

GitHub Pages(Jekyll)로 운영합니다. 저장소에 변경이 올라가면 1~2분 안에 https://osstemunion.github.io 에 반영됩니다.

## 집행부용: 내용 고치는 법

가장 쉬운 방법은 **Pages CMS 관리 화면**(https://app.pagescms.org)입니다. GitHub 계정으로 로그인하고 이 저장소를 고르면 아래 메뉴가 보입니다.

| 하고 싶은 일 | 관리 화면 메뉴 | 직접 고칠 파일 |
|---|---|---|
| 공지·소식 올리기 | 노조소식 → 새로 만들기 | `_posts/날짜-영문이름.md` |
| 자주 묻는 질문 추가 | 자주 묻는 질문 | `_data/faq.yml` |
| 자료 올리기 | 자료실 → 파일 올리기 | `_data/library.yml`, 파일은 `files/` |
| 임원 이름 공개 | 조직도 | `_data/organization.yml` |
| 연혁 추가 | 걸어온 길 | `_data/timeline.yml` |
| 가입·오픈채팅 주소 변경 | 가입·오픈채팅 링크 | `_data/links.yml` |

새 소식을 올리면 노조소식 목록, 메인 화면 최신 소식, NEW 표시(14일)가 자동으로 바뀝니다.

## 밴드 글 자동으로 가져오기

밴드 본문에 **`#홈페이지`** 를 넣은 글만 매일 오전 8시쯤 노조소식에 자동으로 올라갑니다.

- 글의 **첫 줄**이 제목이 됩니다.
- **`#활동소식` `#교섭소식` `#성명`** 중 하나를 함께 쓰면 그 분류로 올라갑니다. 없으면 '공지'입니다.
- 사진도 함께 올라갑니다.
- `#홈페이지` 가 없는 글은 절대 가져오지 않습니다.
- 한 번 가져온 글은 다시 가져오지 않습니다. 밴드에서 고치거나 지워도 홈페이지에는 반영되지 않으니, 홈페이지 쪽은 관리 화면(노조소식)에서 고치거나 지워 주세요.
- 바로 올리고 싶으면 저장소 **Actions → 밴드 → 노조소식 가져오기 → Run workflow** 를 누르세요.

### 처음 한 번만 설정

1. 밴드 운영진 계정으로 **BAND 개발자센터**(https://developers.band.us)에 로그인합니다.
2. 서비스를 하나 등록하고, 안내에 따라 **접근 토큰(Access Token)** 을 발급받습니다.
3. 이 저장소의 **Settings → Secrets and variables → Actions → New repository secret** 에서 이름을 `BAND_ACCESS_TOKEN`, 값을 토큰으로 저장합니다.
4. **Actions → 밴드 → 노조소식 가져오기 → Run workflow** 를 한 번 실행합니다. 실행 결과 화면에 내 밴드 목록과 `band_key` 가 나옵니다.
5. 노조 밴드의 `band_key` 를 같은 방법으로 `BAND_KEY` 라는 이름의 비밀값으로 저장합니다.
6. 다시 Run workflow 를 눌러 글이 잘 올라오는지 확인합니다.

토큰은 비밀번호와 같습니다. 비밀값(Secrets)에만 넣고 파일이나 채팅에는 적지 마세요.

## 주의

- 자료실은 **누구나 볼 수 있는 공개 공간**입니다. 설문 원자료, 회의록 같은 내부 자료는 올리지 마세요.
- 큰 영상은 저장소 대신 유튜브(일부공개)에 올리고 주소만 연결하는 것을 권장합니다.

## 폴더 구조

```
_config.yml       사이트 이름, 설명 등 기본 설정
_data/            FAQ, 자료실, 조직도, 연혁, 링크 (표 형식 데이터)
_posts/           노조소식 글 (글 하나 = 파일 하나)
_layouts/         공통 틀 (머리, 메뉴, 꼬리)
_includes/        머리, 꼬리 등 조각
assets/           공용 디자인(css), 편의 기능(js)
images/ videos/ files/   이미지, 영상, 자료 파일
index.html 등     각 메뉴 페이지
notice-00X.html   예전 주소 → 새 주소로 자동 이동
```
